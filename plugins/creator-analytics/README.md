# Creator Analytics & Insights Add-on Plugin

Standalone Add-on Plugin for CreatorPulse providing advanced creator analytics and admin aggregated intelligence.

## Features
- **Creator Dashboard Analytics**: Profile views, follower growth, subscriber metrics & churn, post/reel/story performance, engagement score, revenue trends, top performing content.
- **Admin Aggregated Intelligence**: Platform-wide metrics, creator leaderboards, format distributions, peak activity hours.
- **Interactive Controls**: Date range filtering (`7d`, `30d`, `90d`, `12m`, custom), sorting, search.
- **Visual SVG Charts**: Profile views & traffic distribution, follower growth, revenue channels (subscriptions, tips, pay-per-view).
- **Export Engines**: Export report data in CSV, JSON, or Print/PDF formats.
- **Database Migrations**: SQL schema for analytics events, daily snapshots, and content metrics.
- **Plugin SDK v1.0 Compliant**: Full lifecycle support (`onInstall`, `onActivate`, `onDeactivate`, `onUpdate`, `onUninstall`), hooks, settings schema, permissions, and active status guards.
